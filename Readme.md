# TrybeWallet

Carteira para controle de gastos em várias moedas, com conversão para real usando cotações em tempo real.

> Projeto desenvolvido durante o curso de Desenvolvimento Web da [Trybe](https://www.betrybe.com/) (2023).

## Funcionalidades

- Login com e-mail e senha
- Cadastro de despesas com valor, moeda, forma de pagamento e categoria
- Cotações atualizadas pela [AwesomeAPI](https://docs.awesomeapi.com.br/)
- Total gasto convertido para BRL no cabeçalho
- Edição e exclusão de despesas

## Stack

React 18 · Redux · TypeScript · React Router · Vite · Vitest · React Testing Library

## Como rodar

```bash
npm install
npm run dev
```

Testes:

```bash
npm test
```
